# IOF — Intelligent Oscillator Framework

> *This system does not seek to control. It seeks to harmonize.*
> *The best oscillations are the ones that surprise you.*

A cross-platform phase-synchronization engine with heterogeneous adaptive nodes.
Runs on Android, iOS, and PC. No cloud. No dependencies beyond numpy + websockets.

## The idea
Twelve oscillators. Four node types. One golden-ratio harmony metric.
The network doesn't converge to order — it converges to *balance*.

## Quick start
```bash
pip install numpy websockets
python iof.py          # console mode (works everywhere)
python iof.py gui      # desktop GUI
python iof.py server   # websocket server
python iof.py demo     # one-shot analysis
```

## Platform notes
- **Android (Termux):** `pkg install python clang && pip install numpy websockets`
- **iOS (a-Shell / Pythonista):** `pip install numpy`
- **PC:** just works
